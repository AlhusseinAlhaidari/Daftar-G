# دفترچي (Daftar-G)

**دفتر ديون ذكي وآمن لأصحاب المحلات الصغيرة**

## نظرة عامة

دفترچي هو تطبيق Flutter مصمم خصيصاً لأصحاب المحلات الصغيرة لإدارة ديون الزبائن والمصروفات بطريقة بسيطة وفعالة. يهدف التطبيق إلى استبدال الدفتر الورقي التقليدي بحل رقمي آمن وسهل الاستخدام.

## الميزات الرئيسية

### 🏠 الشاشة الرئيسية
- عرض قائمة بجميع الزبائن مع أرصدتهم
- إحصائيات سريعة: إجمالي الديون وإجمالي المبالغ الدائنة
- شريط بحث للعثور على الزبائن بسرعة
- ألوان واضحة: أحمر للمدينين، أخضر للدائنين

### 👤 إدارة الزبائن
- إضافة زبائن جدد مع الاسم ورقم الهاتف
- عرض كشف حساب مفصل لكل زبون
- واجهة تشبه المحادثات لسهولة القراءة
- إضافة ديون وسدادات بنقرات قليلة

### 💰 إدارة المعاملات
- تسجيل المشتريات (ديون جديدة)
- تسجيل المدفوعات (سدادات)
- إضافة وصف اختياري لكل معاملة
- عرض تاريخ كامل للمعاملات

### 📊 إدارة المصروفات
- تسجيل مصروفات المحل
- فئات مصروفات محددة مسبقاً
- إمكانية إضافة فئات مخصصة
- تتبع إجمالي المصروفات

### 📈 التقارير
- تقارير شهرية مفصلة
- إحصائيات المبيعات والمقبوضات
- تحليل المصروفات حسب الفئة
- حساب صافي الدخل
- إحصائيات الزبائن (مدينون، دائنون، رصيد صفر)

## التقنيات المستخدمة

- **Flutter**: إطار العمل الرئيسي للتطبيق
- **Provider**: إدارة الحالة
- **SQLite**: قاعدة البيانات المحلية
- **Font Awesome**: الأيقونات
- **Material Design**: تصميم واجهة المستخدم

## هيكل المشروع

```
lib/
├── models/
│   ├── customer.dart          # نموذج بيانات الزبون
│   └── transaction.dart       # نموذج بيانات المعاملة
├── providers/
│   └── app_provider.dart      # مزود إدارة الحالة
├── screens/
│   ├── home_screen.dart       # الشاشة الرئيسية
│   ├── customer_screen.dart   # شاشة تفاصيل الزبون
│   ├── add_customer_screen.dart # شاشة إضافة زبون
│   ├── add_expense_screen.dart  # شاشة إضافة مصروف
│   └── reports_screen.dart    # شاشة التقارير
├── services/
│   └── database_service.dart  # خدمة قاعدة البيانات
└── main.dart                  # نقطة البداية
```

## التثبيت والتشغيل

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/AlhusseinAlhaidari/Daftar-G.git
   cd Daftar-G/daftar_g_app
   ```

2. **تثبيت التبعيات:**
   ```bash
   flutter pub get
   ```

3. **تشغيل التطبيق:**
   ```bash
   flutter run
   ```
