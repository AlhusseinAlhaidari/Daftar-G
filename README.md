## 📖 نظرة عامة

دفترچي هو تطبيق Flutter حديث ومتطور مصمم خصيصاً لأصحاب المحلات الصغيرة لإدارة ديون الزبائن والمصروفات بطريقة بسيطة وفعالة وآمنة. يهدف التطبيق إلى استبدال الدفتر الورقي التقليدي بحل رقمي متكامل يعمل على جميع المنصات.

### لماذا دفترچي؟

- ✅ **سهل الاستخدام**: واجهة بديهية لا تحتاج إلى تدريب
- ✅ **سريع وفعال**: أداء عالي واستجابة فورية
- ✅ **آمن وموثوق**: نسخ احتياطي تلقائي عبر Google Drive
- ✅ **متعدد المنصات**: يعمل على iOS، Android، Web، Windows، macOS، وLinux
- ✅ **قابل للتخصيص**: ثيمات متعددة وألوان قابلة للتخصيص
- ✅ **مجاني ومفتوح المصدر**: بدون إعلانات أو رسوم خفية

## 🎯 المميزات الرئيسية

### 🏠 الشاشة الرئيسية
- عرض قائمة شاملة بجميع الزبائن مع أرصدتهم
- إحصائيات سريعة: إجمالي الديون، المبالغ الدائنة، والمصروفات
- شريط بحث ذكي للعثور على الزبائن بسرعة
- ألوان واضحة: أحمر للمدينين، أخضر للدائنين، رمادي للمتوازنين

### 👤 إدارة الزبائن
- إضافة وتعديل وحذف الزبائن بسهولة
- حفظ معلومات الاتصال (الاسم ورقم الهاتف)
- عرض كشف حساب مفصل لكل زبون
- واجهة تشبه المحادثات لسهولة القراءة والفهم

### 💰 إدارة المعاملات
- تسجيل المشتريات (ديون جديدة) بنقرات قليلة
- تسجيل المدفوعات (سدادات) بسرعة
- إضافة وصف اختياري لكل معاملة
- عرض تاريخ كامل ومفصل للمعاملات
- حساب تلقائي للأرصدة

### 📊 إدارة المصروفات
- تسجيل مصروفات المحل بفئات محددة
- فئات مصروفات محددة مسبقاً (إيجار، رواتب، كهرباء، إلخ)
- إمكانية إضافة فئات مخصصة
- تتبع إجمالي المصروفات بدقة

### 📈 التقارير والإحصائيات
- تقارير مالية شاملة ومفصلة
- إحصائيات المبيعات والمقبوضات
- تحليل المصروفات حسب الفئة
- حساب صافي الدخل تلقائياً
- إحصائيات الزبائن (مدينون، دائنون، متوازنون)

### 🎨 التخصيص والإعدادات
- **نظام ثيمات متقدم**: فاتح، داكن، أو تلقائي
- **تخصيص الألوان**: اختر من 10 ألوان أساسية مختلفة
- **دعم عملات متعددة**: دينار عراقي، دولار، يورو، وغيرها
- **تنسيقات تاريخ مختلفة**: اختر التنسيق المناسب لك

### ☁️ النسخ الاحتياطي والاستعادة
- نسخ احتياطي آمن عبر Google Drive
- استعادة البيانات بنقرة واحدة
- حماية البيانات من الفقدان
- مزامنة عبر الأجهزة المختلفة

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية

- Flutter SDK 3.22.2 أو أحدث
- Dart 3.4.3 أو أحدث
- محرر نصوص (VS Code، Android Studio، أو IntelliJ IDEA)

### خطوات التثبيت

1. **استنساخ المستودع**
```bash
git clone https://github.com/AlhusseinAlhaidari/Daftar-G.git
cd Daftar-G
```

2. **تثبيت التبعيات**
```bash
flutter pub get
```

3. **تشغيل التطبيق**
```bash
# للويب
flutter run -d chrome

# للأندرويد
flutter run -d android

# لـ iOS
flutter run -d ios
```

## 💡 الاستخدام

### البدء السريع

1. **إضافة زبون جديد**: اضغط على زر "إضافة زبون" في الشاشة الرئيسية
2. **تسجيل معاملة**: اضغط على اسم الزبون، ثم اضغط الزر الأحمر (+) للدين أو الأخضر (-) للدفعة
3. **عرض التقارير**: اضغط على أيقونة التقارير في الشاشة الرئيسية
4. **تخصيص التطبيق**: اذهب إلى الإعدادات واختر الثيم واللون المفضل
